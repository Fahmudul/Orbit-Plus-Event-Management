## Purpose

This document identifies the final Figma screens selected for the university project report.

## Final Report Screens

### REPORT-01 — Participant Registration

Demonstrates participant account registration and required account information.

### REPORT-02 — Event Discovery

Demonstrates event search, filtering, event cards, dates, venues, and registration fees.

### REPORT-03 — Event Details

Demonstrates complete event information, organizer details, availability, deadline, and registration action.

### REPORT-04 — Registration Summary

Demonstrates review of event and registration information before confirmation.

### REPORT-05 — Participant Dashboard

Demonstrates upcoming and previous registrations and their statuses.

### REPORT-06 — Create Event

Demonstrates organizer event creation and required event information.

### REPORT-07 — Registered Participants

Demonstrates participant information, registration statuses, export, and communication actions.

### REPORT-08 — Attendance Check-In

Demonstrates participant search, attendance status, check-in, and duplicate check-in prevention.

### REPORT-09 — Sponsorship Submission

Demonstrates sponsorship-opportunity information and submission for a selected event.

### REPORT-10 — Sponsorship Analytics

Demonstrates attendee count, engagement, and reach for a completed sponsored event.

### REPORT-11 — Admin Approvals and User Management

Demonstrates organizer, volunteer/staff, and sponsor approval management.

### REPORT-12 — Event Monitoring

Demonstrates administrative monitoring of event status and registration activity.

## Design System

The selected screens reuse the existing Orbit Plus:

- Color system.
- Typography.
- Sidebar and navigation patterns.
- Buttons and form controls.
- Tables and cards.
- Status badges.
- Spacing system.
- Auto Layout patterns.
- Reusable components.

## Scope Control

The screens avoid unsupported functionality such as:

- Ticket scanning.
- Financial dashboards.
- Discount codes.
- Certificates.
- Complex team permissions.
- Marketing automation.
- Chat.
- Advanced reports.
