# Orbit Plus — Requirements Summary

## Purpose

This document provides a concise summary of the approved Orbit Plus requirements. It does not introduce new business functionality. The complete requirement definitions remain available in the Software Requirement Specification.

## Participant Module

### Main Features

- Account registration and login.
- Email verification.
- Password recovery.
- Event search and filtering.
- Event detail viewing.
- Event registration.
- Registration review and confirmation.
- Registration cancellation.
- Participant dashboard.
- Registration notifications.
- Participant profile management.

### Requirement Coverage

- User Stories: US-01 through US-06
- Functional Requirements: FR-01 through FR-15

## Organizer Module

### Main Features

- Organizer application.
- Administrative account approval.
- Application decision notification.
- Event creation and publication.
- Required-field validation.
- Event editing before the event date.
- Participant and registration management.
- Participant-data export.
- Communication of important event changes.
- Organization and profile management.

### Requirement Coverage

- User Stories: US-07 through US-10
- Functional Requirements: FR-16 through FR-19

## Volunteer / Staff Module

### Main Features

- Assignment to specific events.
- Assigned-event dashboard.
- Assigned-event details.
- Participant-list access.
- Attendance management.
- Duplicate check-in prevention.
- Event-status updates.
- Basic assigned-event reporting.

### Requirement Coverage

- User Stories: US-11 through US-13
- Functional Requirements: FR-20 through FR-23

## Sponsor Module

### Main Features

- Sponsor registration.
- Account review before activation.
- Sponsorship-opportunity discovery.
- Category and date filters.
- Expected reach and audience information.
- Sponsorship submission for a selected event.
- Completed sponsored-event analytics.
- Sponsor profile management.

### Requirement Coverage

- User Stories: US-14 through US-16
- Functional Requirements: FR-24 through FR-27

## Admin Module

### Main Features

- Organizer account approval.
- Volunteer/staff account approval.
- Sponsor account approval.
- User search and management.
- Account suspension and deletion.
- Event monitoring.
- Event-listing dispute handling.
- Category management.
- System settings.
- Platform analytics.
- Platform-wide announcements.

### Requirement Coverage

- User Stories: US-17 through US-20
- Functional Requirements: FR-28 through FR-32

## Non-Functional Requirements

Orbit Plus includes quality requirements covering:

- Performance.
- Scalability.
- Security.
- Availability and reliability.
- Usability.
- Responsive behavior.
- Browser compatibility.
- Maintainability.
- Privacy.
- Validation and error-message clarity.
- Account and personal-data deletion requests.
