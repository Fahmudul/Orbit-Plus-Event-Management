# Orbit Plus — Project Overview

## Project Title

Orbit Plus — Event Management Platform

## Project Type

University Software Engineering project focusing on Software Requirement Specification, Scrum planning, system design, UI/UX design, requirement traceability, and software testing documentation.

## Background

University events, workshops, competitions, conferences, cultural programs, and career fairs are often managed through disconnected tools such as social media posts, online forms, spreadsheets, emails, and messaging applications.

This fragmented process makes it difficult for participants to discover events, monitor their registrations, and receive important updates. Organizers also face difficulties when creating events, managing participant records, communicating changes, and maintaining accurate attendance information.

Orbit Plus provides one centralized platform for event discovery, registration, event administration, sponsorship, attendance management, and platform monitoring.

## Project Objective

The objective of Orbit Plus is to provide a unified event-management platform that supports the complete event lifecycle while maintaining clear permissions for every user role.

The system aims to:

- Make event discovery easier for participants.
- Simplify event creation and participant management for organizers.
- Support attendance and assigned-event operations for volunteers and staff.
- Allow sponsors to discover sponsorship opportunities and monitor sponsored-event performance.
- Provide administrators with account approval, user management, event monitoring, and platform analytics.
- Improve communication between participants, organizers, volunteers, sponsors, and administrators.

## Primary User Roles

Orbit Plus supports five major user roles.

### Participant

Participants can:

- Register and log in.
- Search and filter published events.
- View complete event information.
- Register for events.
- Review registration details before confirmation.
- Track registration status.
- Cancel registrations before the allowed deadline.
- View upcoming and previous registrations.
- Receive event and registration notifications.
- Update their profile.

### Organizer

Organizers can:

- Apply for an organizer account.
- Receive approval or rejection from an administrator.
- Create and publish events after approval.
- Edit their events before the event date.
- View registered participants.
- Manage registration statuses.
- Export participant information.
- Communicate important event changes.
- Update organization and contact information.

### Volunteer / Staff

Volunteers and staff can:

- View events assigned to them.
- View the participant list for an assigned event.
- Manage participant attendance.
- Prevent duplicate check-in.
- Update assigned-event status.
- View and download basic assigned-event reports.

### Sponsor

Sponsors can:

- Submit sponsor registration information.
- Wait for account review and approval.
- Browse events that are open for sponsorship.
- Filter sponsorship opportunities.
- View expected reach and audience information.
- Submit sponsorship details for a selected event.
- View attendee count, engagement, and reach for completed sponsored events.
- Update sponsor profile information.

### Administrator

Administrators can:

- Approve or reject organizer, volunteer/staff, and sponsor applications.
- Search and manage user accounts.
- Suspend or delete accounts that violate platform rules.
- Monitor events and registration activity.
- Resolve duplicate, fraudulent, or inappropriate event listings.
- Manage event categories and system settings.
- View platform analytics.
- Send platform-wide announcements.

The Orbit Plus UI/UX design is available at:

The design follows a modern EventTech SaaS visual direction and uses a consistent design system for colors, typography, navigation, forms, tables, cards, status badges, and reusable components.

## Project Scope Limitation

Orbit Plus does not include unrelated functionality such as:

- Ticket scanning.
- Complex payment or accounting systems.
- Revenue and ROI analytics.
- Discount codes.
- Certificate generation.
- Marketing automation.
- Complex organizational permissions.
- Chat or messaging systems.
- Advanced scheduling systems.

The project remains focused on the functionality defined in the approved SRS.
